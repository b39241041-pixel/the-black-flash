# The Black Flash 🌑⚡

A free unblocked games website — play HTML5 games at school, browse privately with a built-in proxy, stream movies and music.

## 🚀 Live Site

[**theblackflash.github.io**](https://theblackflash.github.io) *(update with your actual URL)*

## ✨ Features

- ⚡ 30+ unblocked HTML5 games with search & category filters
- 🌐 Built-in web proxy (Ultraviolet/Scramjet-ready)
- 🎬 Movies & 🎵 Music sections
- 🌌 Animated starfield canvas background
- 📱 Fully responsive with mobile sidebar
- 🎮 In-page game modal with fullscreen support
- 🟣 Dark purple "Black Flash" color theme

## 🗂 Structure

```
petezah-clone/
├── index.html   # Main page
├── style.css    # All styles
├── app.js       # Interactivity (starfield, games, search, modal)
└── logo.svg     # Lightning bolt logo
```

## 🛠 Dev

Just open `index.html` in a browser — no build step required.

To add real games, edit the `GAME_URLS` map in `app.js` with iframe-embeddable URLs.
